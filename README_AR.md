# Binance Signal App — النسخة الأولى

تطبيق Android تجريبي يعطي إشارات BUY/SELL مع Entry و SL و TP1/TP2/TP3، ويقرأ بيانات ETHUSDT من Binance.

## البناء من الهاتف

1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد.
2. افتح تبويب Actions.
3. اختر Build Android APK.
4. اضغط Run workflow.
5. بعد نجاح العملية افتح العملية الأخيرة ثم Artifacts.
6. نزّل `binance-signal-app-release` وفك الضغط لتحصل على APK.

ملف APK في هذه النسخة غير موقّع للنشر على Google Play، لكنه مناسب للاختبار على الهاتف.

## ملاحظات
- التطبيق يستخدم بيانات Binance العامة ولا يحتاج API Key في هذه النسخة.
- الإشارة الحالية تجريبية وتعتمد على EMA 9/21 وATR.
- لا يوجد تنفيذ صفقات تلقائي.
- لا تعتبر الإشارات توصية مالية أو ضمانًا للربح.
